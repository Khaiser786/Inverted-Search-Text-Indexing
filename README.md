Project Brief:
 Developed a text indexing system that creates an index of words across multiple files, enabling faster keyword-based searches using hashing and linked-list data structures.

Technologies Used:
 Advanced C, Hashing, Linked Lists, File I/O, Dynamic Memory Allocation, Data Structures

Key Challenges & Learnings:

Designing and implementing an efficient hash table.
Managing collisions using linked lists.
Parsing and indexing multiple text files.
Understanding search optimization techniques.
